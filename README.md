## 🛠 Project Overview

This Python script serves as a lightweight utility for tracking pool run performance. By automating the summation of competition tasks, it reduces manual calculation errors during testing and practice sessions.

### Key Features

* **Independent Development:** Built by the MATEROV REEF student team.
* **Simple Interface:** Interactive command-line prompts for quick data entry.
* **Instant Summation:** Uses a simple arithmetic logic to provide immediate feedback.
